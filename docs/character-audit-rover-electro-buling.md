# 전도 방랑자·복링 데이터 기록

2026-09-29 확인. 여우의 별자리의 전자 파티에 편성할 수 있도록 두 캐릭터와 파티 제공 버프를 추가했다. 기존 JSON 형식과 [버프 기록 규칙 v2](buff-recording-rules-v2.md)를 따른다.

## 분석·기본 장비 정책

| 항목 | 방랑자 · 전도 | 복링 |
|---|---|---|
| ID | `rover_electro` | `buling` |
| 90레벨 HP / 공격력 / 방어력 | 10775 / 437 / 1136 | 10625 / 225 / 1259 |
| 무기 / 속성 | 직검 / 전도 | 증폭기 / 전도 |
| 대표 피해 | 전도 공명 스킬 | 강화 해방 비뢰결 · 귀일 |
| 연결점 상시 적용 | 공격력 12%, 크리티컬 8% | 공격력 12%, 치료 효과 12% |
| 필요 공명 효율 기본값 | 120% | 180% |
| 기본 무기 | 천년의 회류 | 판타지 변주 |
| 기본 세트 / 메인 에코 | 떠오르는 구름 / 음험한 백로 | 찬란한 광휘 / 돌아갈 곳이 없는 오류 |

두 캐릭터 모두 공격력 기반 대표 피해를 기존 방식으로 분석한다. 실제 사이클 DPS나 복링의 회복량을 계산하는 모델은 아니다. `matrix_cost: 1`, `43311`, 명함·1공진 시작은 프로젝트 기본 정책이며 게임 내 희귀도나 파티 기여도 판정이 아니다. 스킬 노드는 항상 적용하고 추가 버프 목록에서 숨긴다.

전도 방랑자의 기본 운용은 과부하를 짧게 사용하고 반주로 퇴장하는 지원 운용이다. 임계 공명은 여러 속성 공격을 포함하므로 현재 전도 대표 피해를 전체 임계 공명 사이클로 해석하지 않는다. 과부하를 길게 사용할 때의 스킬 보너스와 5돌 크리티컬 피해는 기본 해제한다. 별도의 피해 점유율이나 전투 자세 모드는 만들지 않았다.

공명 효율은 에너지 소모량을 옮긴 값이 아니다. 전도 방랑자는 Genshin Builds의 약 120% 목표를 사용한다. 복링은 명함 기준 Prydwen의 160~180% 범위 중 180%를 초기값으로 선택했다. 2돌 후에는 같은 가이드의 예시 파티에서 125~135%까지 낮아지지만, 여우의 별자리 파티에서 검증된 수치가 아니므로 돌파만으로 자동 변경하지 않는다. 사용자 설정으로 조절할 수 있다.

장비 추천 순서는 접근성과 파티 지원을 고려한 편집 판단이다. 전도 방랑자의 거울 세트(`flash_of_electric_reflection`)는 전자 부여 후 다음 캐릭터에게 전도 보너스를 줄 수 있는 대안으로 등록했다. 복링의 파도의 기록·꼭두각시의 손은 개인 피해용 대안, 심해의 메아리는 회복용 대안이다. 뭇별의 교향곡의 파티 공격력은 **공명 스킬 치료**가 조건이므로, 이를 발동하지 못하는 복링의 추천에서 제외했다. 전용 무기는 둘 다 없다.

## 전도 방랑자 효과 판정

| 효과 | 적용 |
|---|---|
| 과부하 짧게 발동 | 파티 공격력 10%, 20초. 본인 포함, 기본 활성 |
| 중추 귀환 | 과부하 길게 발동 후 자기 공명 스킬 보너스 20%, 20초. 교대 종료, 기본 해제 |
| 반주 | 다음 캐릭터가 20초 내 이상 효과를 추가하면 전체 피해 25% 부스트, 14초. 교대 종료. 본인 제외 |
| 3·4·6돌 | 각각 과부하, 최종 전략, 밀려온 천개의 소리·천둥의 추락 배율 20% 증가. 모두 `record_only` |
| 5돌 | 임계 공명 중 자기 크리티컬 피해 20%. 일반 스탯 증가이므로 계산 가능하되 기본 해제 |

가드·1돌의 경직 저항과 피해 감소, 고유 스킬의 전자 10스택, 2돌의 전자 5스택, 자원·협주 소모, 임계 공명 자원 회복·기류 치료량은 스탯 버프로 변환하지 않는다. 전자 스택이나 추가 공격의 피해를 일반 피해 보너스로 합산하지 않는다.

## 복링 효과 판정

| 효과 | 적용 |
|---|---|
| 퇴마진 중 변주 1회 | 등장 캐릭터 공명 스킬 보너스 10%. 퇴마진은 24초 지속 |
| 퇴마진 중 변주 2회 | 위 효과가 25%로 교체되므로 추가분 15%만 별도 기록 |
| 6돌 | 위 25%가 50%로 교체되므로 추가분 25%만 기록. `10 + 15 + 25 = 50%` |
| 반주 | 파티 전체 피해 15% 부스트, 30초. 다음 한 명으로 제한하지 않음 |
| 고유 스킬 | HP 50% 미만 대상 치료 시 치료 효과 25%, 기본 해제 |
| 1돌 | 대표 피해인 비뢰결 · 귀일의 크리티컬 20%. 공명 해방 유형에만 적용, 상시 항목 표시 |
| 4돌 | 치료 효과 20%, 상시 항목 표시. 치료 효과 자체는 피해 점수에 기여하지 않음 |

회로 버프는 온필드 수혜를 가정한 `party` 항목이다. 퇴마진의 오프필드 피해에 같은 버프가 항상 적용된다는 의미는 아니다. 변주 두 번을 거치는 파티 운용을 기본으로 두며, 한 번만 거쳤다면 두 번째 증가분과 6돌 증가분을 끈다. 기존 다른 스택 버프와 같이 선행 토글 상태를 강제하지 않는다.

1돌 효과를 일반 공격·공명 스킬·기본 비뢰결·전자 효과로 확장하지 않는다. 2돌 에너지 25pt 회복을 공명 효율 25%로 입력하지 않는다. 강공격·변주·반주·3돌의 회복량, 고유·퇴마진·5돌의 전자 스택, 부조화 감소·자원·체력 소모는 계산 범위 밖으로 문서에만 남긴다.

## 여우의 별자리 연동

- 여우의 별자리 전자 모드의 고유 효과 중 방랑자에게 돌아가는 전도 보너스 20%를 `hsin_electro_rover_party`로 추가했다. `specific_character: rover_electro`, 30초이며 다른 파티원은 받지 않는다.
- 기존 여우의 별자리 본인 수혜 항목 `hsin_electro_rover_self`와 전자 부여 두 번째 스택 `hsin_electro_stack2`는 수동 토글·기본 해제 정책을 유지한다. 전도 파티를 구성했다면 해당 조건에 맞춰 켠다. 편성만으로 자동 활성화하지 않는다.
- 파티원이 미저장 상태라면 명함 고유 버프만 제공한다. 복링의 돌파와 양쪽 장비를 저장하면 해당 설정이 파티 버프에 반영된다.
- 이상 효과 부여 여부, 다음 등장 순서와 버프 시간은 시뮬레이션하지 않는다. 전도 방랑자의 반주 조건과 복링의 변주 횟수는 각 항목의 설명·토글로 관리한다.

## 이미지·검증

- 캐릭터 이미지는 Genshin Builds의 게임 에셋 CDN에서 받아 확인했다. [방랑자](https://images.genshin-builds.com/wuthering/characters/portrait_rover_electro.webp), [복링](https://images.genshin-builds.com/wuthering/characters/portrait_buling.webp). 방랑자는 남성 이미지 한 장을 대표로 사용한다.
- 기존 무기·세트·메인 에코와 이미지를 재사용한다. 이름 미공개인 `hsin_main_echo`는 기존 임시 표시를 유지한다.
- `tests/engine/rover-buling.test.ts`: 기본 장비 연결, 지원/임계 공명 조건, 기록 전용 배율 제외, 복링 돌파별 25/50% 합산, 수혜 피해유형, 저장 장비 전달, 마스터 미적용, 여우의 별자리 특정 캐릭터 수혜를 검사한다.
- 검증 결과: 전체 39개 테스트 파일의 265개 테스트 통과, TypeScript·Vite 빌드 통과. 두 분석 경로와 이미지의 localhost HTTP 200을 확인했다. 연결된 브라우저가 없어 화면 클릭 검증은 수행하지 않았다.
