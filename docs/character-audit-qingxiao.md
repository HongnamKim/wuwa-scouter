## 캐릭터와 분석 기본값

`qingxiao`: 기류·직검·공격력 스케일, 기초 공격력 462. 연결점은 크리티컬 피해 `(2.4+5.6)×2=16%`, 공격력 `(1.8+4.2)×2=12%`다.

피해유형별 분석 모드는 제거하고 기존 갈브레나와 같은 `damage_type_mix` 가중 근사를 사용한다. 대표 유형 `heavy_attack`은 표시용으로 유지하며, 일반·강공격·공명 스킬·공명 해방 보너스를 모두 유효 부옵으로 반영한다. 에코 피해는 무기·버프의 가중 계산에 포함하지만 에코 피해 보너스 부옵은 게임에 없으므로 유효 부옵에는 넣지 않는다.

화면의 유효옵 합계·비교 요약·최고점 부옵 설명에서는 점유율이 작은 공명 스킬 항목을 생략한다. 에코 옵션 입력과 실제 점수 계산에는 공명 스킬 피해 보너스 및 기존 1.4% 점유율을 그대로 유지한다.

2026-09-15 사용자가 Prydwen에서 확인해 전달한 차트 수치는 아래와 같다. 직접 읽은 Prydwen 본문에는 차트 수치가 없었고 HTML·차트 데이터 요청은 HTTP 403으로 실패했다. 따라서 **점유율의 근거는 사용자 전달값**이며 차트 원문을 직접 검증한 것으로 표시하지 않는다. 차트의 돌파·무기·파티 기준은 전달되지 않아 S0 등의 조건을 임의 지정하지 않았다.

| 피해유형 | 전달값 | 계산 가중치 |
|---|---|---|
| 일반 공격 | 22.8% | 228 / 1001 |
| 강공격 | 31.2% | 312 / 1001 |
| 공명 스킬 | 1.4% | 14 / 1001 |
| 공명 해방 | 28.5% | 285 / 1001 |
| 변주 | 1.3% | 13 / 1001 (무유형 잔여분) |
| 반주 | 10.8% | 108 / 1001 (무유형 잔여분) |
| 에코 | 4.1% | 41 / 1001 |

전달값 합계 100.1%는 표시 반올림으로 보고 전부 같은 비율로 정규화했다. `damage_type_mix`의 5개 유형 합은 `880/1001`, 변주·반주의 잔여 비중은 `121/1001`이다. 잔여분을 삭제하거나 강공격 등에 재분배하지 않는다. 이 잔여분에도 공통 공격력·크리티컬·기류 보너스는 적용하되, 유형별 피해 보너스는 적용하지 않는다.

3돌의 원문 크리티컬 피해 증가량은 +100%다. 이를 해방 비중으로 환산한 `1.0×285/1001=0.28471528471528473`을 가중 크피로 저장한다. 사용자에게는 원문 효과인 공명 해방 크리티컬 피해 +100%만 표시하며, 점유율·가중 근사 설명은 내부 note와 이 문서에 남긴다. 해방 모드 조건을 제거했으므로 이전 저장 모드가 남아 있어도 동일하게 계산한다.

**근사 한계:** 점유율은 모든 돌파·장비·파티에서 고정한다. 원문 배율·추가타는 계속 기록 전용이며 점유율 재산출에 사용하지 않는다. 현재 엔진은 피해 보너스·부스트·크피를 각각 가중한 뒤 곱하므로, 유형별로 서로 다른 보너스와 해방 전용 크피를 적용한 타격별 합산과는 차이가 있다. 3돌 가중 크피는 인게임 캐릭터 창의 공통 크피 증가량이 아니다. 차트에 이미 돌파 효과가 포함되어 있는지도 미확인 상태이며, 이 데이터는 전체 사이클 DPS를 재현하는 계산이 아닌 고정 비중 기반 에코 옵션 근사다.

기본 코스트는 43311, 필요 공명 효율은 125%로 둔다. 125%는 한국어 전재 가이드의 여유 있는 목표치를 택한 편집값이며, 에너지 소모량을 변환한 값이 아니다. Prydwen은 조합에 따라 110~115%를 제시하므로 실제 파티에 맞춰 조절할 수 있다.

추천은 옥빛 구름·악을 씻어내는 마음·겁살을 기본으로 한다. 이미 등록된 대체 직검 중 날카로운 봄·푸른 의지·천년의 회류·예리한 날개깃을 표시한다. 무기 순서는 전체 사이클 성능 순위가 아니다. 미등록 대체 세트나 경연의 장비는 이번 범위에 포함하지 않는다.

## 최고점 탐색 성능

유효 부옵이 5종에서 8종으로 늘면서 기존 전수 탐색의 청초 기본 최고점 계산이 약 18~21초 걸리는 문제가 재현됐다. 유형 보너스들은 같은 증가항에 선형 합산되므로, 해당 부옵의 총 줄 수가 같다면 `점유율×최고 단계 값`이 높은 종류를 5줄까지 우선 배분하는 해가 항상 우월하다. 이 지배관계를 이용해 열등한 배분만 제외하고 공격력·크리티컬 등의 배분은 계속 전수 탐색한다. 실제 입력한 부옵은 모두 원래 점유율로 계산한다.

최적화 후 같은 환경에서 청초 최고점과 메인 추천을 합친 테스트가 약 0.33초에 완료됐다. 작은 구성의 독립 전수 탐색과 결과가 같음을 비교하며, 기존 단일 유형 탐색은 유지한다.
