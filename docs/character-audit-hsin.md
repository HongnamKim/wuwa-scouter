# 여우의 별자리 데이터 기록

2026-09-28 작성. 3.7 전반 캐릭터이며, 사용자가 대화에 제공한 한국어 나무위키 스킬·공명 체인·90레벨 스탯·무기·세트 설명을 수치의 기준으로 삼았다. 웹에서 확인했던 이전 해외 자료의 공격력·지속 시간·전자 배율보다 사용자 제공 본문을 우선한다.

## 분석 기준

- 사용자 지정: 청초의 점유율 가중 방식을 사용하지 않고, 기존 단일 유형 캐릭터처럼 **공명 스킬 피해**를 대표 피해로 분석한다. `damage_type_mix`는 만들지 않는다.
- 합일 / 전자 두 분석 모드를 제공한다. 만상의 화응 / 만상의 비춤은 전투 자세이므로 분석 모드로 추가하지 않는다.
- 90레벨 HP 10,300 / 기초 공격력 462 / 방어력 1,112. 기본 공명 효율 100%, 크리티컬 5%, 크리티컬 피해 150%는 기존 엔진 공통값을 사용한다.
- 스킬 노드 크리티컬 8%, 공격력 12%는 상시 반영하며 추가 버프 패널에는 표시하지 않는다.
- 필요 공명 효율은 검증된 사이클 목표가 제공되지 않아 기본 100%로 두었다. 최적 권장 수치라는 의미가 아니며 사용자가 조정할 수 있다.
- 코스트 기본값은 기존 43311. 출시 전 검토할 수 있도록 접근 잠금은 설정하지 않았다.

## 효과별 판정

| 원문 효과 | 데이터와 적용 범위 |
|---|---|
| 합일 고유 스킬 | 강화 변주 후 공격력 +50%, 8초. 교대 종료. 합일 모드만, 기본 활성 |
| 전자 고유 스킬 | 캐릭터당 전도 피해 +25%, 최대 2스택. 본인 부여 1스택만 기본 활성, 다른 캐릭터에 의존하는 2스택은 기본 해제 |
| 전도 방랑자 변주 | 본인 전도 피해 +20%, 30초. 파티 조건을 수동 확인하는 토글이며 기본 해제. 전도 방랑자가 데이터에 없어 방랑자의 수혜 경로는 이번 범위 밖 |
| 합일·합일 대응·고유 스킬 | 합일 가능 캐릭터의 최종 피해는 기록 전용. 기본 상한 2, 고유 스킬로 3, 6돌로 4스택. 상한과 실제 보유량은 별개 |
| 합일 반주 | 본인 제외, 합일 획득으로 서로를 비추는 등불을 보유한 캐릭터만 전체 피해 20% 부스트. 30초. 수혜 조건 자동 판별 미지원이므로 파티 토글 기본 해제 |
| 전자 반주 | 본인 제외 파티원의 전도 피해 20% 부스트, 20초. 밤을 밝히는 빛은 전투 진입 또는 해방 마무리 후 획득. 모드 전환 종료 |
| 1돌 | 합일 변주 배율 기본 15% 및 스택당 10%는 각각 기록 전용. 전자 배율 계수 175→210%, 35→42%는 교체 효과로 기록 |
| 2돌 | 지정 강화 강공격 네 종류의 배율 60% 증가는 기록 전용 |
| 3돌 배율·전자 | 마무리 배율 70% 증가와 전자 스택당 1500% 추가 피해는 기록 전용 |
| 3돌 크리티컬 피해 | **무수히 하늘을 뒤덮은 궁궐만** 20% + 15% × 합일 스택. 기본 해제된 3스택 65% 토글. 이 공격을 대표 피해로 볼 때 켜는 기존 히유키 방식이며, 전체 사이클 또는 모든 공명 스킬에 공통 적용되는 효과라는 뜻이 아니다 |
| 4돌 | 조건 충족 시 파티 전체 속성 피해 +20%, 30초. 본인 포함 |
| 6돌 공명 스킬 | 받는 공명 스킬 피해 +40%와 방어력 무시 20%는 기존 `absolute_score_only` 항목으로 분리. 취약은 기존 부스트 버킷 근사이며 일반 공명 스킬 피해 보너스로 변환하지 않음 |
| 6돌 합일 | 4번째 스택의 크리티컬 피해 추가 15%만 별도 토글. 3돌 토글과 함께 켜면 80%. 기본 해제. 기존 엔진은 스택 토글 간 선행 조건을 강제하지 않음 |
| 6돌 전자 | 크리티컬 80% / 크리티컬 피해 230%는 전자 효과 한정 고정값으로 기록. 일반 크리티컬에 가산 금지 |

합일 최종 피해, 전자 스택·추가타는 현재 대표 피해 계산의 범위 밖이다. 특정 스킬 배율은 모두 `record_only`로 저장한다. 일반 유형 부스트·방어력/저항 무시는 기존 문서 v2 §3의 비교용 계산을 유지한다. 같은 설정에서 상수로 적용될 때 상대 에코 점수에서 약분되지만, 서로 다른 무기 비교에서는 차이가 남는다.

스태미나, 자원 회복·상한, 합일에 따른 교대·협주 소비, 전자 자동 결산·스택 유지, 칙령 협동 공격, 변신 및 기관 통솔 시간, 1돌 경직 저항·피해 감소, 2돌 자원·쿨타임 초기화, 5돌 피해 감소·부활은 버프 스탯으로 만들지 않는다. 특히 회복량을 HP 증가로, 자원 pt를 공명 효율로 변환하지 않는다.

## 무기·세트·메인 에코

- **옥궐에 피는 꽃**: 기초 공격력 587, 크리티컬 24.3%. 전체 속성 보너스 12/15/18/21/24%, 스킬 부스트 36/45/54/63/72%, 스킬의 전도 저항 무시 10/13.5/17/20.5/24%를 분리. 전자 피해 부스트 30/37.5/45/52.5/60%는 기록 전용. 전자 부여·합일 대응 조건, 30초, 출전 범위·동명 최고값 조건을 보존한다.
- **꿈으로 세상을 비추는 마음**: 2세트 전도 10%, 5세트 조건부 크리티컬 15% + 전도 22.5%, 30초. 2세트 증가분을 5세트 값에 중복 포함하지 않는다.
- **거울 그림자에 번개가 스치는 찰나**: 2세트 전도 10%, 5세트 전자 부여 후 본인 전도 10%와 반주 후 다음 변주 캐릭터 전도 25%를 분리. 각각 15초. 합일 모드 사용만으로 전자 부여가 가능한 것은 아니므로 착용자가 발동 조건을 충족하는지 토글로 관리한다.
- **메인 에코**: 사용자 확인상 이름 미공개. 임시 식별자 `hsin_main_echo`, 표시명 `신규 에코 (이름 미공개)`를 두 세트에서 공유하며 기존 목록 중복 제거를 따른다. 이미지 미공개로 기본 아이콘 사용. 장착 전도 10% + 조건 충족 시 추가 10%, 30초. 에코 공격 배율(일반 4×27.36%+164.16%, 전용 5×13.68%+232.56%)과 쿨타임 20초는 공격·운용 정보로만 기록한다.
