# 유노·아우구스타 데이터 검수

2026-09-14. 캐릭터의 스킬·공명 회로·고유 스킬·변주/반주·체인 1~6에서 버프와 기록 대상 효과를 대조했다. 전용 무기의 기초 스탯과 공진 1~5도 확인했다. 추천 세팅·필요 공명 효율은 수동 정책으로 유지하며, 모든 공격의 레벨별 계수를 계산기에 추가하는 작업은 아니다.

원문은 나무위키 미러 및 스킬 전재 자료다. 게임 내 실측 검증과 구분한다. 사용자 기준에 따라 특정 스킬 배율·추가타는 계산에서 제외하고, 스키마에 없는 실드·자원·사이클 효과는 아래 표에 기록한다.

## 두 전용 무기

| 무기 | 수치 확인·수정 |
|---|---|
| 세상 만물의 진리 | 기초 공격력 500·크리티컬 36%, 공진별 공격력 12~24%·해방 보너스 20~40%·방어력 무시 36~60% 일치. 방어력 무시를 `target_damage_bonus_type: resonance_liberation`으로 제한 |
| 천둥벼락을 다스리는 권능 | 기초 공격력 675·크리티컬 12.1%, 공진별 공격력 12~24%·강공격 보너스 20~40%·방어력 무시 36~60% 일치. 방어력 무시를 `target_damage_bonus_type: heavy_attack`으로 제한 |

두 무기의 방어력 무시는 실드 획득으로 쌓으며, 0.5초 간격·최대 5스택·7초 지속이다. 유노 전무의 변주 최대 스택 간주는 **3초**다. 아우구스타 전무에는 해당 변주 효과가 없으므로 잘못된 문구를 삭제했다. 최대 스택 유지 가정은 각 캐릭터의 반복 실드 획득에 근거한다. [유노 전무 원문](<https://namu.moe/w/유노(명조:%20워더링%20웨이브)>), [아우구스타 전무 원문](<https://namu.moe/w/명조:%20워더링%20웨이브/무기/대검>)

피해유형 제한은 현재 주력 유형에 적용한다. 혼합 피해의 타격별 방어력 무시를 분배하는 기능은 아니다.

## 계산 경계·검증

- `critScaleValue`의 기존 정수 내림 정책은 유지한다. 원문의 “1%당”만으로 게임이 정수 단위 변환한다고 확정할 수 없어 실측 확인 대상으로 남긴다.
- 113%가 부동소수점에서 112.99999999999999%로 표현되어 초과분이 12%로 잘리는 오류를 보정했다. 113% → 크리티컬 피해 26%, 112.9999% → 24%로 정수 내림 경계를 유지한다.
- [회귀 테스트](../tests/engine/iuno-augusta.test.ts): 무기의 피해유형 제한·공진, 유노 5돌 상시 적용, 아우구스타 돌파별 스택 합계·초과분 경계·상한, 기록 전용 효과의 계산 제외를 검증한다.
- 기존 ID는 유지한다. 새로운 실드/자원 타입이나 교대 시뮬레이션은 도입하지 않았다.
- 검증 결과: 추가 회귀 테스트 17개 및 전체 28개 파일·160개 테스트 통과. TypeScript 검사·Vite 빌드·`git diff --check` 통과. 별도 코드 리뷰에서 중대 이슈 없음.
